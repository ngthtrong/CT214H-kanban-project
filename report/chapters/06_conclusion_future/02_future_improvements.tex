\section{Future Improvements}

The current system establishes a strong baseline; the next iteration can focus on product maturity:
\begin{enumerate}
    \item Add real-time board synchronization (WebSocket or event polling).
    \item Introduce password reset and optional social login integrations.
    \item Extend notification flows (due-date reminders, join-request updates).
    \item Increase automated test coverage, including API contract tests.
    \item Add audit logging for sensitive actions (role changes, deletions, file updates).
    \item Improve analytics dashboards for workload distribution and deadline risk.
    \item Evolve toward multi-tenant hard isolation for broader SaaS deployment goals.
\end{enumerate}
