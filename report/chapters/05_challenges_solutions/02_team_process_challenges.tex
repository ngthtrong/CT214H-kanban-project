\section{Team and Process Challenges}

\subsection{Module Ownership and Integration}

The project was split into four module tracks (Auth/UI, Project/Members, Tasks, Search/Database).
A key process challenge was preserving consistent behavior across independently developed modules.
The team reduced integration friction through:
\begin{itemize}
    \item Shared API response shape using \code{success/data/error} conventions.
    \item Central helper utilities in \code{includes/functions.php} and \code{includes/session.php}.
    \item Early agreement on fixed Kanban statuses: \code{todo}, \code{in\_progress}, \code{done}.
\end{itemize}

\subsection{Balancing Simplicity and Maintainability}

A documented simplification moved authentication from a heavier OOP structure to function-oriented logic.
This improved explainability for course presentation while preserving core security controls
(password hashing, CSRF checks, session hardening).

\subsection{Testing and Quality Maturity}

Quality scripts exist, but comprehensive automated coverage is still maturing.
The current setup supports incremental improvements by combining:
\begin{itemize}
    \item Functional testing with PHPUnit.
    \item Style checks with PHPCS.
    \item Static smell detection with PHPMD.
\end{itemize}
