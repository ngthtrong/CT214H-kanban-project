\section{Layered Architecture}

The implementation follows a three-layer architecture:
\begin{itemize}
    \item \textbf{Presentation Layer}: server-rendered pages and client-side interactions.
    \item \textbf{Application Layer}: API routing and domain-function modules in \code{includes/}.
    \item \textbf{Data Layer}: MySQL schema, integrity constraints, and transactional data access.
\end{itemize}
