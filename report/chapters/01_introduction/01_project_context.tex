\section{Project Context}

Team Kanban is a web application developed for the CT214H Web Programming course.
The project targets student teams that need a lightweight but complete workspace to coordinate assignments,
track progress, and submit artifacts.

The implementation stack follows the course requirements:
\begin{itemize}
    \item Backend: PHP 8.x.
    \item Database: MySQL 8.x.
    \item Frontend: HTML5, CSS3, and JavaScript.
    \item Core deliverables: CRUD, form validation, search/filter, file upload, and pagination.
\end{itemize}

The report is built from two evidence sources:
\begin{itemize}
    \item Project briefs and specification documents in the \code{docs/} folder.
    \item The current source code in root PHP pages (for example \code{index.php}, \code{project.php}, and \code{task.php}), together with \code{api/}, \code{includes/}, \code{js/}, \code{css/}, and \code{database/}.
\end{itemize}
