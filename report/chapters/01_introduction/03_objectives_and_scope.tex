\section{Objectives and Scope}

\subsection{Primary Objectives}

The project objectives extracted from the briefs and implementation are:
\begin{itemize}
    \item Deliver secure user registration, login, logout, and profile management.
    \item Provide project workspace creation with role-aware collaboration.
    \item Implement full task lifecycle management in a three-column Kanban board.
    \item Support task search/filter and paginated retrieval for scalability.
    \item Enforce safe file upload for avatars and task attachments.
\end{itemize}

\subsection{Out-of-Scope Items}

The current version intentionally excludes advanced capabilities:
\begin{itemize}
    \item Social login and password reset by email/OTP.
    \item Real-time board synchronization via WebSocket.
    \item Advanced role hierarchy beyond owner and member.
    \item Full-text search engine integration (for example ElasticSearch).
\end{itemize}
