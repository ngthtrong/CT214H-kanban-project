\section{Problem Statement}

Student teams often manage tasks through fragmented tools (messaging apps, spreadsheets, and ad-hoc notes),
which creates four major problems:
\begin{enumerate}
    \item No unified project board for transparent progress tracking.
    \item Weak ownership and permission boundaries between team members.
    \item Difficult task discovery when boards become large.
    \item Inconsistent handling of task artifacts and proof files.
\end{enumerate}

The Team Kanban system addresses these issues through a centralized Kanban board model with role-based access,
search and filtering, and attachment support.
The target users are students acting as either:
\begin{itemize}
    \item \textbf{Project Owner}: can manage projects, members, and all tasks.
    \item \textbf{Project Member}: can work on assigned tasks, claim unassigned tasks, and update own task progress.
\end{itemize}
