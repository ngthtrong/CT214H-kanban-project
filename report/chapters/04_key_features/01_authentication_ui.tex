\subsection{Behavior Summary}

The authentication module includes:
\begin{itemize}
    \item Registration with duplicate checks for username and email.
    \item Login by username or email with bcrypt password verification.
    \item Session creation, timeout control, and session hijacking checks.
    \item Profile update (name and email), password change, and avatar upload.
\end{itemize}

\subsection{Security Controls}

Security controls visible in source code include:
\begin{itemize}
    \item Password hashing with \code{password\_hash(..., PASSWORD\_BCRYPT)}.
    \item CSRF token generation and verification in form submissions.
    \item Input sanitization and validation in both UI forms and backend functions.
    \item Session hardening through HTTP-only cookies and regeneration on login.
\end{itemize}
