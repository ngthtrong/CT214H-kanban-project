# BRIEF-00003: Quản lý Task

## Thông tin cơ bản

- **Người tạo**: Huỳnh Hồng Ân
- **Ngày tạo**: 2026-03-27
- **Priority**: High

## Bối cảnh & Vấn đề

Bảng Kanban không thể thiếu đi các thẻ công việc (Task). Các thành viên trong nhóm cần có công cụ định nghĩa công việc, giao việc, nhận việc, thao tác cập nhật tiến độ (drag & drop qua lại giữa các cột) và lưu trữ tài nguyên nộp bài/báo cáo tại các task này.

## Mục tiêu

- Người dùng có thể tạo, xem chi tiết, sửa và xóa Task tại Project được cấp quyền.
- Hỗ trợ luồng giao việc: Owner có thể assign task và Member có thể tự claim task.
- Cho phép thao tác kéo-thả (Drag & Drop) visual các task card để chuyển trạng thái Kanban.
- Hỗ trợ Upload File (hình ảnh, tài liệu) đính kèm cho mỗi task.

## Mô tả Chi tiết

- Phát triển API và màn hình cho CRUD thực thể Task.
- Thực hiện cơ chế Drag & Drop thông qua Javascript tương tác với PHP API để cập nhật trạng thái trong database (cột hiện tại).
- Quản lý tính năng gán việc (Assignee) vào member cụ thể hoặc hủy gán.
- Xử lý quá trình tải lên (Upload) file đính kèm với những ràng buộc an toàn, thể hiện được trên UI.

### User Stories (nếu có)

- Với tư cách là Member, tôi muốn Kéo thẻ task từ "To Do" qua "In Progress" để Cập nhật tiến độ tức thời cho cả nhóm nắm bắt.
- Với tư cách là Owner, tôi muốn Gán task "Báo cáo tiến độ" cho bạn Trọng để Phân chia vai trò rõ ràng.
- Với tư cách là Member, tôi muốn Upload file PDF báo cáo vào task để Nộp thành quả công việc đã hoàn thành.

### Các tình huống quan trọng

- Ngăn chặn việc thành viên (Member) xóa task hoặc sửa nội dung task của người khác. Member chỉ được phép update (tính cả drag and drop) các task do mình làm.
- Cần validation khi upload: giới hạn dung lượng 5MB, và chỉ cho phép đuôi file an toàn (jpg, png, doc, docx, pdf).
- Khi drag elements rớt ajax thì handle UI re-bounce (trả về trạng thái cũ).

## Ràng buộc & Giới hạn

- **Kỹ thuật**: Sử dụng HTML5 Drag and Drop API hoặc script nhẹ (tránh các thư viện kéo thả quá cồng kềnh). Xử lý call API bất đồng bộ.
- **Kinh doanh**: Tích hợp chặt chẽ việc File Upload theo đúng yêu cầu minium của bài tập.

## Out of Scope

- Real-time Board Update (Sử dụng Websocket, Polling... để tự động di chuyển trên máy của user khác).
- Bình luận (Comments) bên trong task card.
- Label có màu tùy chỉnh tự tạo, Checklist nhỏ trong nội dung task.
