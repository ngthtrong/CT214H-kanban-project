# BRIEF-00002: Quản lý Project & Members

## Thông tin cơ bản
- **Người tạo**: Huỳnh Hồng Ân
- **Ngày tạo**: 2026-03-27
- **Priority**: High

## Bối cảnh & Vấn đề
Mỗi nhóm học tập cần một không gian (Project board) để tổ chức công việc cộng tác. Cần có cơ chế để sinh viên tạo dự án, quản lý dự án và luồng thành viên tham gia (mời, gia nhập bằng mã, phê duyệt, xóa).

## Mục tiêu
- Người dùng có thể tạo project mới và tự động trở thành Owner của project đó.
- Hệ thống cấp một mã code (8 ký tự ngẫu nhiên) cho mỗi project để làm công cụ chia sẻ.
- Người dùng có thể mời thành viên khác bằng email/username hoặc gia nhập thông qua mã project.
- Owner có quyền quản lý danh sách thành viên (xem, xóa) và duyệt/từ chối các yêu cầu tham gia.
- Hiển thị project workspace theo dạng bảng Kanban (To Do, In Progress, Done).

## Mô tả Chi tiết
- Các chức năng quản lý Project (Tạo mới, xem danh sách, cập nhật thông tin, xóa project cascade data).
- Các chức năng quản lý thành viên (Gửi và duyệt yêu cầu gia nhập dự án).
- Triển khai HTML/CSS/JS cho Dashboard và Project Board.
- Phân quyền theo Role hiển thị và thao tác UI giữa Owner (toàn quyền) và Member (quyền giới hạn).

### User Stories (nếu có)
- Với tư cách là Owner, tôi muốn Tạo project và Copy mã dự án để Mời bạn bè cùng tham gia.
- Với tư cách là Sinh viên, tôi muốn Nhập mã project từ bạn bè để Gửi yêu cầu gia nhập dự án.
- Với tư cách là Owner, tôi muốn Duyệt yêu cầu join để Kiểm soát số lượng và thành phần tham gia project.

### Các tình huống quan trọng
- Xóa project phải xóa sạch tất cả mọi thứ liên quan kể cả file đính kèm, tasks và members (On Delete Cascade).
- Xóa member khỏi project phải làm trống lại (set NULL) các task đang phân công cho member đó.
- Người dùng cố gắng join một project mà họ đã là thành viên (handle duplicate requests).

## Ràng buộc & Giới hạn
- **Kỹ thuật**: UI Modal sử dụng Javascript thuần dựa trên API PHP (AJAX).
- **Kinh doanh**: Đáp ứng yêu cầu CRUD đối với thành phần tham gia dự án.

## Out of Scope
- Tùy chỉnh việc thêm/bớt/đổi tên các cột trạng thái Kanban (chỉ chốt 3 cột cố định).
- Hệ thống roles phức tạp (Nhờ các roles ngoài như Viewer, Administrator... - chỉ cần Owner và Member).
