### Short Explanations

1. Question 1: Intro web materials often split applications into pure network apps and standalone apps.
2. Question 2: A set of pages under one domain is a website.
3. Question 3: A browser is client software that accesses and renders web content.
4. Question 4: The key distinction is server-side processing in dynamic websites.
5. Question 5: Front-end work is included in Front-End and Full-Stack roles.
6. Question 6: Website structure belongs to the design phase.
7. Question 7: Screen-adaptive design is responsive design.
8. Question 8: Browsers render content, not raw HTML tags themselves.
9. Question 9: The frame tag was removed in HTML5.
10. Question 10: Repeating the same attribute is invalid; the first value is effectively retained.
11. Question 11: `dir="rtl"` reverses left-to-right text display, producing cba.
12. Question 12: `rel="icon"` links a file used as the site icon.
13. Question 13: The viewport meta setting enables proper responsive behavior on devices.
14. Question 14: `strong` has semantic emphasis and accessibility meaning.
15. Question 15: `img` uses `src`, not `url`.
16. Question 16: A rectangular area requires 4 coordinates: x1, y1, x2, y2.
17. Question 17: The default target value is `_self`.
18. Question 18: Option A groups structural semantic HTML elements.
19. Question 19: Vertical merge across two rows uses `rowspan="2"`.
20. Question 20: `iframe` embeds another page inside the current page.
21. Question 21: The odd-number rule is used in composition/layout decisions.
22. Question 22: HTML does not allow nested forms.
23. Question 23: `action` should be a valid destination URL; `index.html` is valid.
24. Question 24: File upload requires `multipart/form-data`.
25. Question 25: Self-closing submit input with value is valid.
26. Question 26: `accept=".png,.jpeg"` is a valid extension filter.
27. Question 27: Data in the query string indicates GET.
28. Question 28: In structure-vs-presentation separation, structure is HTML.
29. Question 29: CSS3 was modularized.
30. Question 30: `property: value;` is one declaration.
31. Question 31: A linked stylesheet can be reused site-wide.
32. Question 32: Combined id/class/tag selector syntax in option C is valid.
33. Question 33: Multiple conditions on the same element use chained attribute selectors.
34. Question 34: Selecting either extension requires multiple selectors; B is the closest valid option.
35. Question 35: `ul li` is a descendant combinator selector.
36. Question 36: `+` is the adjacent sibling combinator.
37. Question 37: Specificity is 0 0 2 2.
38. Question 38: The later matching rule applies, resulting in blue.
39. Question 39: Element creation uses `createElement`; option A is the only one with that API.
40. Question 40: `\d{10}` matches exactly 10 digits.
